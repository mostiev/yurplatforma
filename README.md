# Юрплатформа (рабочее название)

Сайт, который собирает юридические документы по ответам человека. Право РФ.

## Как открыть

Двойной клик по `index.html` — сайт откроется в браузере. Ничего устанавливать не нужно.

## Как устроено

- `index.html` — каталог всех документов (готовые и «скоро»).
- `d/<id>.html` — страница документа.
- `assets/engine.js` — движок: анкета по шагам, условия, проверка ответов, предпросмотр.
- `assets/docx.js` — сборка Word-файла прямо в браузере, без библиотек.
- `content/<id>.js` — сам документ: вопросы, логика веток, текст шаблона, инструкция «что делать дальше».
- `content/catalog.js` — список всех 60 позиций реестра.
- `tests/` — проверки логики: `node tests/d01.test.js`.

Ответы человека никуда не отправляются: документ собирается в его браузере. Поэтому сейчас на сервере нет персональных данных.

## Статус документов

Статусы и юридическая сверка ведутся в реестре документов. Документ со статусом `draft` показывается с плашкой «Черновик: не проверен юристом». До проверки юристом сайт не публикуется.

## Как добавить документ

1. Скопировать `content/d01.js` → `content/dNN.js`, переписать вопросы, `derive`, `stop`, `render`, `guidance`.
2. Создать страницу: `node tools/make-page.js dNN "Заголовок для поиска" "Описание для поиска"`.
3. В `content/catalog.js` поставить `live: true`.
4. Написать `tests/dNN.test.js` по образцу `tests/d02.test.js` и запустить.

## Готово

- Д-01 — претензия о товаре с недостатком (ст. 18–24 ЗоЗПП).
- Д-02 — возврат исправного товара: в магазине (ст. 25) и онлайн (п. 4 ст. 26.1).
- Д-03 — возврат денег за онлайн-курс (ст. 32 ЗоЗПП, ст. 782 ГК).
- Д-04 — претензия за некачественную услугу или работу (ст. 29–31 ЗоЗПП).
- Д-05 — возврат за авиабилет и штраф за задержку рейса (ст. 108, 120, 127.1 ВК РФ; ФАП-82 в ред. приказа № 341).
- Д-07 — возврат денег за абонемент в фитнес-клуб или салон (ст. 32 ЗоЗПП).
- Д-08 — отмена подписки и возврат автосписаний (ст. 32, п. 4.2 ст. 16.1 ЗоЗПП).
- Д-09 — претензия туроператору (ст. 9, 10, 14 закона о туризме; ст. 29, 32 ЗоЗПП).
- Д-10 — претензия автосервису (ст. 16, 28, 29, 35 ЗоЗПП; ПП № 780).
- Д-11 — платная клиника и стоматология (ст. 29, 32 ЗоЗПП; ст. 22, 84 323-ФЗ).
- Д-12 — договор найма квартиры (гл. 35 ГК, ст. 381.1 ГК).

Общие куски текста (шапка, подпись, способы возврата) — в `assets/common.js`.

Все — черновики до проверки юристом.

Запустить все проверки: `for f in tests/d*.test.js; do node $f | tail -1; done`
